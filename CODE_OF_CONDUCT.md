
# Code of Conduct

AROMA aims to maintain a professional, constructive, and research-focused
collaboration environment.

Participants are expected to:

- discuss technical disagreements respectfully;
- critique methods, evidence, and claims rather than people;
- document uncertainty and negative results honestly;
- avoid harassment, discrimination, or personal attacks;
- respect dataset licenses, model licenses, authorship, and attribution;
- preserve the integrity of frozen research records.

Serious concerns should be raised privately with the repository maintainer
when appropriate.
