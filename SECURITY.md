
# Security Policy

Do not commit:

```text
API keys
Hugging Face access tokens
SSH private keys
cloud credentials
personal credentials
private dataset credentials
```

If you discover a credential or security issue in the repository, please use
GitHub's private security-reporting mechanism when available rather than
posting the secret in a public issue.

The repository-integrity workflow performs lightweight checks for common
credential patterns, but it is not a replacement for proper secret management.
