# AROMA 2.0 Residual-Response Rescue Protocol

## Status

Exploratory follow-up motivated by the pre-specified Stage 1A Gate 0 result.

The original Gate 0 decision remains:

NO_GO_WEAK_SIGNAL

This protocol does NOT retroactively redefine or overturn Gate 0.

## Motivation

Gate 0 found:

- Static-39 mean action Spearman: ~0.268
- Response-38 mean action Spearman: ~0.275
- Static+Response mean action Spearman: ~0.332

Response alone therefore did not outperform static state meaningfully,
but Static+Response showed statistically detectable complementarity.

This motivates a new exploratory hypothesis:

    intervention response may be more useful as a correction
    to errors made by a static utility estimator than as a
    standalone replacement representation.

## Residual-response formulation

For each action a,

    U_hat_res(x,a)
        = U_hat_static(x,a)
        + Delta_hat_response(x,a)

where Delta_hat_response is trained to predict the residual

    U(x,a) - U_hat_static(x,a).

Residual targets must be generated by inner cross-fitting.
The outer evaluation fold must never contribute labels to the
residual targets used to train its response model.

## Fixed model family

For every regression stage:

    StandardScaler -> Ridge(alpha=0.01)

No hyperparameter search.

## Fixed outer evaluation

5-fold StratifiedKFold by procedural condition.

Random seed:

    20260914

## Fixed policy rule

Non-NOOP actions:

    {0.0, 1.5, 2.0, 4.0}

NOOP:

    alpha = 1.0

Select the highest predicted non-NOOP utility only if:

    max predicted utility > 0.1

Otherwise abstain / NOOP.

The threshold 0.1 is not tuned in this experiment.

## Compared representations

Existing Gate-0 models:

1. Static39
2. Response38
3. NaiveConcat = Static39 + Response38

Residual-response models:

4. Residual_J
5. Residual_K
6. Residual_JK

Residual_JK is the PRIMARY exploratory rescue model.

J-only and K-only are mechanistic ablations and may not replace
Residual_JK as the primary model after results are observed.

## J / K definition

J features:

- 16 first-order probability response terms
- first-order expected-numeral response
- first-order entropy response
- first-order margin response

K features:

- 16 second-order probability curvature terms
- second-order expected-numeral curvature
- second-order entropy curvature
- second-order margin curvature

J has 19 dimensions.
K has 19 dimensions.
J+K has 38 dimensions.

## Primary practical endpoint

Difference in OOF net accuracy gain:

    Residual_JK - Static39

using the fixed policy threshold.

## Secondary endpoint

Difference in mean per-action Spearman:

    Residual_JK - Static39

## Pre-specified RESCUE-GO criterion

All must hold:

1. Residual_JK improves OOF net accuracy gain over Static39 by
   at least +1.0 percentage point.

2. Paired bootstrap 95% CI lower bound for that policy-gain
   difference is > 0.

3. Residual_JK improves mean action Spearman over Static39 by
   at least +0.05.

4. Bootstrap 95% CI lower bound for the mean-Spearman difference
   is > 0.

5. Residual_JK is non-inferior to Static39 in action-wise
   Spearman for at least 3 of 4 non-NOOP actions.

If all five hold:

    RESCUE_GO

If both point estimates are positive but the full criterion fails:

    RESCUE_WEAK_NO_GO

Otherwise:

    RESCUE_NO_GO

A weak result does not justify natural-domain GPU collection.

## Interpretation discipline

This experiment is exploratory because the residual hypothesis was
generated after observing Gate 0.

A positive result may motivate a separately frozen natural-domain
confirmation experiment.

It is not itself confirmatory evidence of cross-domain transfer.
